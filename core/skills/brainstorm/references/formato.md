# Brainstorm — variante com clusters

Quando há > 6 ideias de temas distintos, acrescentar entre `## Ideias` e `## Picks`:

```
## Clusters
### <tema>
- <ideia>
```

O SWOT do top cluster (versão antiga, tabela 2x2) passa a ser opcional: usar a skill `swot` em modo Standard.

## Exemplo

```
# Brainstorm: acelerar o arranque do vault

## Ideias
- Cache do índice de wikilinks — evita varrer o vault
- Resumo diário pré-gerado — contexto pronto
- Cortar skills de arranque — menos bytes

## Picks
1. Cortar skills de arranque — ganho certo, risco baixo
   - Next: correr context-budget e listar as 3 maiores
```
